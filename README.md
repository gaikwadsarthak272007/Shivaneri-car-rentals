## Publish on GitHub Pages
1. Extract this ZIP on your computer.
2. Create a GitHub repository (for example, shivneri-car-rentals).
3. Upload index.html, style.css, app.js and the assets folder to the repository ROOT. Upload the extracted files, not the ZIP. Keep the folder structure.
4. Commit the files to main.
5. Open Settings > Pages > Build and deployment.
6. Select Deploy from a branch, choose main and /(root), then Save.
7. When deployment finishes, use the Visit site link shown in Pages settings.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Edit or copy the code
Open index.html, style.css and app.js in VS Code or any text editor. No build or installation is required. Open index.html in a browser for a local preview. Online fonts require internet; system fonts are the fallback.

## Features
Four model cards with six vehicles total; car filtering; booking details; date validation; price estimate; all ten rental rules in English and Marathi; SMS, WhatsApp and copy options.

## Booking behaviour
This is a static website. Submit prepares an SMS addressed to +917058179915 and opens the visitor's messaging app. The visitor must tap Send. SMS charges may apply. WhatsApp and copy options are provided for unsupported devices. The website does not store bookings or automatically transmit an SMS. Availability and final billing require confirmation by Yash Rajendra Nere.
Automatic SMS would require a separate secure backend and SMS provider. Never put secret API keys in this public code.
